Setup Service Account Google Drive

Web server katalog ini membaca video, foto time-lapse, dan file analisis eksperimen langsung dari Google Drive menggunakan kredensial Service Account yang aman tanpa batas kuota login harian.

1

Buat Project Google Cloud & Aktifkan Google Drive API

Lakukan persiapan awal di konsol Google Cloud Platform.

  1. Buka Google Cloud Console dan buat Project baru (contoh: grain-sandbox-server).
  2. Masuk ke menu APIs & Services > Library.
  3. Cari "Google Drive API" lalu klik tombol ENABLE (Aktifkan).
2

Buat Service Account & Unduh File Kredensial JSON

Unduh key file JSON dan upload langsung ke form di bawah ini.

  1. Masuk ke menu IAM & Admin > Service Accounts → Klik Create Service Account.
  2. Beri nama (contoh: grain-catalog-reader) → Klik Done.
  3. Klik Service Account yang baru dibuat → Buka tab KEYS → Add Key > Create new key > JSON → File .json akan terunduh otomatis ke komputer Anda.

Tarik & Lepaskan file credentials.json ke sini

atau klik untuk memilih file dari komputer

Mengunggah & memvalidasi kredensial...
3

Bagikan (Share) Folder Google Drive ke Email Service Account

Berikan akses baca (Viewer / Editor) ke email Service Account agar server bisa mengakses file.

Email Service Account Anda:
  1. Buka Google Drive di browser → Temukan folder root yang berisi folder-folder eksperimen Sandbox Anda.
  2. Klik kanan pada folder tersebut → Pilih Share (Bagikan).
  3. Paste email Service Account di atas ke kotak input bagikan.
  4. Pilih role sebagai Viewer (atau Editor) → Hapus centang Notify people → Klik Share.
4

Masukkan Google Drive Root Folder ID & PIN Admin

Tentukan ID folder induk yang berisi eksperimen dan PIN otentikasi sinkronisasi.

Cara mengetahui Google Drive Folder ID:

Buka folder di Google Drive, lihat URL di address bar browser Anda:
https://drive.google.com/drive/folders/1a2B3c4D5e6F7g8H9_xyz
Salin bagian kode unik setelah /folders/ tersebut.
